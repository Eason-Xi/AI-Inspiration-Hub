# 灵感扩散库 · AI Inspiration Hub

根据 `AI_Inspiration_Hub_PRD.md` 实现的个人本地 MVP。主流程：记录 → AI 理解与发散 → 保存子节点 → 项目归类 → 搜索找回。

## 启动

需要 Node.js **22.13+**（使用内置 SQLite）；建议使用 Node.js 24 LTS。

```sh
npm install
npm run dev
```

打开 http://127.0.0.1:3003 。默认仅监听本机。首次启动自动添加 6 条明确标记的示例记录和 2 个项目，示例不包含伪造的 AI 结果。

生产方式：

```sh
npm run build
npm start
```

## 已实现

- 文字、Markdown、图片（JPG / PNG / WEBP / GIF，10 MB 以内）、URL；支持粘贴图片及快捷键保存。
- 收件箱、项目创建与浏览、节点归类、手动标签、收藏、状态、归档/恢复、编辑与确认删除。
- 关键词搜索，组合项目/标签/状态/内容类型筛选；服务端分页，每页 18 条。
- OpenAI 兼容模型接口：摘要、关键词、分类、3–5 个发散方向与行动建议；支持默认/实用/创意/反向/产品模式。
- 后台 AI 分析，不阻塞记录保存；失败状态、超时重试、模型输出结构校验。
- 发散方向和行动保存为子节点；父子跳转与行动勾选。
- 图片本地持久化、链接标题与描述的尽力解析；解析失败保留原始 URL。
- SQLite WAL 持久化、JSON 导出、桌面及手机布局。

## 连接 AI

进入「设置」，填写 **API 地址、模型名称、API Key**。连接支持 `/chat/completions` 和 JSON 模式的 OpenAI 兼容服务；图片理解需要服务支持视觉输入。也可复制 `.env.example` 为 `.env.local` 并设置相应环境变量，页面保存的设置优先。

密钥保存在 `data/settings.json`（权限 0600），不会通过 API 返回前端。此文件是本机明文配置；备份时应保护好它。模型服务会接收正在分析的记录内容及图片。新记录保存后自动分析；已有记录可在详情页点击「开始发散」。**没有模型密钥时仍可记录和整理，但不会生成 AI 内容。**

后台处理使用 Next.js `after()`，适用于本地常驻进程；进程中断后需在详情页重试，不提供持久化任务队列。AI 接口已通过本地模拟服务测试；实际模型生成效果需要有效密钥验证。

## 数据与备份

- `data/hub.sqlite`：记录与项目数据库（同时可能存在 WAL / SHM 文件）。
- `data/uploads/`：上传的原始图片。
- `data/settings.json`：本机模型配置。

备份前停止应用，再复制完整 `data/` 目录。恢复时将该目录放回项目根目录。支持用 `DATA_DIR` 环境变量指定独立数据目录。设置页的 JSON 导出仅包含记录、项目及 AI 结果，不包含图片二进制与密钥，尚未提供 JSON 导入。

## 技术与 MVP 边界

Next.js App Router + React + TypeScript + Node.js SQLite。前端由 `src/components` 组织；路由处理器位于 `src/app/api`；数据与模型 Provider 位于 `src/lib`。PRD 的 Supabase 是推荐架构；本阶段采用 SQLite，避免云端项目与密钥成为本地试用的前置条件。未来可替换持久化层接入 Supabase。

当前是**个人本地版**，没有登录、云端同步或多人隔离，API 仅接受本机同源访问；不能直接作为公网多人服务部署。长期版本中的语义搜索、历史自动关联、知识图谱、AI Discover、每周报告和 PDF 解析均未包含。链接解析暂不提供封面截图、正文抽取或受限站点登录抓取。
